# 📥 Fotos nuevas

Arrastrá acá las fotos o logos que quieras poner en la web (cualquier formato: JPG, PNG, HEIC del iPhone…).
Después decile a Claude: **"te dejé fotos nuevas"**.

Claude las mira, te pregunta de qué torneo y año son si no lo reconoce, las achica, les pone el nombre
correcto y las agrega a la página. Los originales quedan guardados en `_procesadas`.
